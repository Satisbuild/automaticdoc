# Konverter

Bog-værktøjer, der kører direkte i browseren på <https://automatikhelp.com/Konverter/>.
De kræver ingen installation, og filerne forbliver på brugerens computer.

| Værktøj | Resultat |
|---|---|
| PDF til Word | `.docx` |
| PDF til Kindle | `.epub` |
| Tekst til PDF | PDF |
| HTML til PDF | PDF via browserens printvindue |
| Billeder til PDF | Søgbar PDF og tekstfil |
| Lyd til PDF | PDF og tekstfil |

Koden ligger i `web/`. Det lokale program med Rens bog, AZW3 og screenshots med F-taster ligger i
repoet Bog_Scripts, i mappen `Hjemmeside`.
