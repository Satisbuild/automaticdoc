# Stationslogoer

Læg officielle logoer her, hvis I har lov til at bruge dem (fx `dr-p3.png`, kvadratisk, gerne 512×512).
Skriv derefter stien i stationens `logo`-felt i `js/stations.js`:

```js
logo: 'assets/radio-logos/dr-p3.png'
```

Uden logo viser GrejsRadio et ensartet farvet mærke med stationens forkortelse.
